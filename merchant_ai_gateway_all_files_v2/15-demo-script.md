# 15 Demo Script

## Goal
Give a short demo flow that makes the product easy to understand.

## Demo Length
About 3 to 5 minutes.

## Demo Order

### 1. Problem
Open by saying that merchants build stores for people, but AI buyers need a safe structured path.

### 2. Product
Show Merchant AI Gateway as the merchant-side layer that talks to AI assistants.

### 3. Request
Enter a sample request such as:
- wireless keyboard under 4000

### 4. Match
Show the catalog search and the selected product.

### 5. Checks
Show budget and stock checks.

### 6. Approval
Show the approval step if needed.

### 7. Razorpay order
Show checkout creation in Razorpay test mode.

### 8. Outcome
Show successful order or a graceful failure.

### 9. Audit trail
Show the timeline of events.

### 10. Session inbox
Show many live sessions and filter one by status.

## Demo Message
The main message should be:
- AI can buy safely
- merchant stays in control
- every money action is explainable
- every money action is logged
- many sessions can be handled at the same time

## Demo Failure Case
Prepare one failure run:
- over budget
- missing shipping details
- out of stock
- payment failure

## Final Line
This product makes Razorpay merchants ready for AI buyers without losing control of checkout.
