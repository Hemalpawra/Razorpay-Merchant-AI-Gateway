# 14 Roadmap

## Goal
Plan the build in a small and realistic sequence.

## Phase 1: Core data
- merchant table
- product table
- session table
- audit table

## Phase 2: Request flow
- accept buyer request
- search catalog
- score products
- show match results

## Phase 3: Safety
- budget checks
- stock checks
- approval checks
- missing detail checks

## Phase 4: Payments
- Razorpay test order
- checkout link
- webhook updates
- payment status sync

## Phase 5: UI
- dashboard
- session inbox
- session drawer
- approval view
- outcome view
- audit trail view

## Phase 6: Scale features
- session claim flow
- pagination
- polling or SSE
- duplicate request protection
- import flow

## Phase 7: Polish
- clearer messages
- better spacing
- better state handling
- tighter audit display

## Phase 8: Demo prep
- dry run
- failure run
- clean visuals
- record script
- final review

## Scope Rule
Do not add new features before the core flow works.

## Roadmap Success
The roadmap is successful if the team can ship a clean, working, and readable demo within the hackathon window.
